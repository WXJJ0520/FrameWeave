**镜织 FrameWeave** 是面向内容创作者、AI 教学博主和个人开发者的本地视频创作工作台。你可以从一个主题开始生成脚本与画面，也可以上传自己的图片、实拍或录屏素材，让 AI 辅助理解内容、组织旁白，再完成配音、模板排版、背景音乐与视频合成。

工作台把快速创作、数字人口播、图生视频、自定义素材和动作迁移放在统一界面中。每个创作页面都按步骤操作，模型配置按用途分组，适合从短片测试逐步扩展到多章节长视频。

![镜织 FrameWeave：纯白工作台与三步创作流程](docs/assets/frameweave-creation-steps.jpg)

## 适合做什么

| 创作需求 | 推荐入口 | 需要准备 |
| --- | --- | --- |
| AI 工具教学、知识讲解、观点分享 | 快速创作 | 一个主题，或一份完整稿件 |
| 产品测评、实拍解说、录屏教程 | 自定义素材 | 图片或视频、讲解方向、目标时长 |

| 角色参考动作与视频编辑 | 动作迁移 | 人物图片、参考动作视频、适配的视频编辑 API |

### 快速创作：从主题到成片

1. 选择 **AI 创作**，输入主题、目标内容和可选标题；已有完整文案时选择 **自行创作**。
2. 设置短片或长视频目标，选择模板、图片 / 视频模型、配音音色、语速与背景音乐。
3. 在最后一步确认参数，提交生成并查看结果。

AI 创作负责文案规划；自行创作保留完整原稿，并按镜头需要拆分长段落。图片模板以配图呈现内容，视频模板按镜头调用视频模型。批量模式按每行一个主题逐条生成短片，不作为完整稿件的批量导入入口。

### 数字人口播：人物图片配合口播内容

使用人物图片和口播文案，先合成参考配音，再调用支持人物图片与声音输入的 API。页面按模型已经接入的能力展示可用选项，并在失败时提示实际阶段，便于区分文案、配音和视频生成问题。还可以补充商品标题与商品图片用于商品讲解；当前生成使用首张人物图和首张商品图，没有直接上传口播音频的入口。

当前接入中的参考声音能力不等同于精确唇形同步；例如 Wan 的参考音频用于音色和口播参考，不能保证逐字复现。数字人口播按所选模型的单段时长工作，不属于 5–10 分钟长片入口。

### 图生视频：让参考图片动起来

上传一张图片，描述主体动作、镜头变化和画面风格，再设置模型支持的时长、画幅或分辨率。可用参数随适配器变化，未实现的能力不会仅因为接口返回了模型名称就自动出现。

适合制作教学插入镜头、产品展示片段或人物动态素材。当前生成使用第一张上传图片；最终片段长度与输出规格仍由所选模型和服务决定。

### 自定义素材：用自己的画面讲完整故事

1. 上传图片、实拍视频或录屏，填写视频标题和“内容方向与讲解要求”。
2. 选择视觉分析服务与模型，设置目标时长、配音、背景音乐和是否启用素材动画。
3. 确认素材与参数后生成：**分析素材 → 编写旁白 → 匹配素材 → 配音与合成**。

短片目标支持 15–120 秒，长片支持 5 / 8 / 10 分钟。视频单文件上传上限为 1 GB；视觉分析图片限制为 32 MB、6400 万像素，发送前进行预处理。视频按时间均匀抽取最多 8 / 16 / 32 帧，附采样时间交给视觉模型。

默认保留原图片和视频用于合成。只有主动启用素材动画时，匹配到的图片才额外调用图生视频 API。预览默认收起并分页，同一会话内切换步骤会复用上传缓存。

### 动作迁移：人物与参考动作组合

提供人物图片和参考动作视频，选择已适配相应输入的视频编辑模型，再设置提示词及可用参数。当前生成使用第一张人物图片与第一段参考视频。该入口按参考视频与图片能力筛选模型；普通文生视频或图生视频模型不会自动充当动作迁移模型。

### 配置、模板与作品管理

- **配置按用途查找**：可以先看“按功能找配置”，再填写实际需要的服务，不必把所有平台都配一遍。
- **模型从接口加载**：保存服务目录后，创作页使用当前连接的模型列表；更换地址、密钥或代理后需要重新加载。
- **模板可定制**：内置模板的默认作者、签名和品牌使用镜织 FrameWeave，也可改成自己的栏目名；已有自定义值保留。
- **记录与下载**：成片在当前创作页面展示，历史记录用于查找已有任务；数字人页面会将记录保存失败与视频生成失败分别提示。
- **会话内保留输入**：前后切步、切换已打开的功能页时保留编辑状态。刷新、关闭页面或重启服务可能清空会话草稿，草稿尚不是持久项目存档。

## 怎样生成 5–10 分钟视频

<!-- 长视频由多个镜头编排合成，不改变供应商单次视频请求的时长限制。 -->
在 **快速创作** 或 **自定义素材** 中选择长视频目标。系统先估算章节、镜头和文案预算，再逐章编写或拆分旁白，完成每个镜头的配音与画面，最后合成为一条完整视频。

```text
主题 / 完整稿件 / 自有素材
           ↓
章节规划与旁白校验
           ↓
镜头编排 → 镜头配音 + 画面生成 / 素材匹配
           ↓
模板渲染、背景音乐与视频合成
           ↓
成片预览、下载与实际时长检测
```

| 长片入口 | 画面来源 | 适用方向 |
| --- | --- | --- |
| 快速创作 + 图片模板 | 逐镜头生成配图 | 知识讲解、图文教学、观点分享 |
| 快速创作 + 视频模板 | 生成多个短视频镜头 | 故事、场景演示、动态画面讲解 |
| 自定义素材 | 使用上传的图片和视频 | 实拍测评、操作教程、素材解说 |

以中文、1.0 倍语速为例，5 分钟约规划 38 个镜头和 1080 字，10 分钟约规划 75 个镜头和 2160 字；这些是规划值，调整语速会改变文案预算。完成后会探测实际时长及与目标的偏差。

长片制作有几个具体边界：

- 目标分钟数不等于单次模型视频长度，也不承诺严格卡在目标秒数；自行创作不会补写或重复原稿来凑时长。
- 快速创作中视频短于旁白时可停留末帧；自定义素材不足时可能复用素材或循环片段。
- 自定义素材长片按时间均匀选取原视频片段，尚未实现“根据一句旁白精确定位某个动作”。
- 素材分析不识别原音轨，成片使用生成旁白与背景音乐，不保留原素材声音。
- 镜头越多，调用量和等待时间通常越大；当前未实现整条长片失败后的自动断点续生成。

## 快速开始

### 环境准备

| 依赖 | 用途 |
| --- | --- |
| Python 3.11+ 与 uv | 后端、创作管线与依赖管理 |
| Node.js 22 与 npm | 构建 React 工作台；版本与现有 CI 一致 |
| FFmpeg / ffprobe | 视频、音频处理和时长检测，需要加入 `PATH` |
| Playwright Chromium | 将 HTML 画面模板渲染成图像 |
| 可访问的模型 API | 文案、素材理解、图片或视频生成，按所用功能配置 |

### 安装

克隆镜织仓库并安装依赖：

```bash
# 获取源码并进入项目目录。
git clone https://github.com/WXJJ0520/FrameWeave.git
cd FrameWeave

# 安装锁定的 Python 依赖。
uv sync --frozen

# 安装模板渲染使用的浏览器。
uv run playwright install chromium

# 安装并构建工作台前端。
npm --prefix studio ci
npm --prefix studio run build
```

Linux 缺少 Chromium 系统依赖时可执行 `uv run playwright install --with-deps chromium`，并安装中文字体，例如 `fonts-noto-cjk`。用 `ffmpeg -version` 和 `ffprobe -version` 确认媒体工具可执行。安装后还应检查 `node --version`；本机存在多个 Node 时，终端可能仍指向旧版本。构建出现 `crypto.getRandomValues is not a function` 时，应先切换到 Node 22 或更新的受支持版本。

### 启动

```bash
# 请在项目根目录运行。
uv run python -m frameweave
```

打开 **[http://127.0.0.1:8765](http://127.0.0.1:8765)**。依赖和前端构建完成后，也可以使用 Windows 的 `start_frameweave.bat`，或 macOS / Linux 的 `bash start_frameweave.sh`。

统一启动器会检查并启动创作服务：`8765` 提供完整工作台，`8501` 提供内嵌创作页面。它只复用能够确认为本仓库的已有创作进程，不会替你停止其他占用端口的程序。退出启动器时，只清理本次创建的子服务。

如需更换工作台端口，设置环境变量 `FRAMEWEAVE_PORT`；创作服务仍使用 `8501`，两者不能相同。独立打开 **[http://127.0.0.1:8501](http://127.0.0.1:8501)** 可以排查创作页面问题。Windows 操作详见[本地运行说明](本地运行说明.md)。

## 模型与 API 配置

### 每组配置用在哪里

| 配置位置 | 用途 | 需要注意 |
| --- | --- | --- |
| 文本模型 | 主题文案、长片章节、素材解说、标题、画面提示词 | 使用 OpenAI 兼容文本 API，独立保存地址、密钥与型号 |
| 图片与视频 → OpenAI | 已适配图片模型，以及自定义素材视觉分析 | 视觉与图片生成共用此提供商配置，不自动复用文本密钥 |
| 图片与视频 → 通义 / DashScope | Wan / HappyHorse 视频能力、通义图片生成与素材视觉分析 | 按具体模型能力筛选，部分接口用于数字人或动作迁移 |
| 图片与视频 → 火山 / ARK | Seedream 图片、Seedance 视频 | 当前目录需在设置中明确手工维护 |
| 图片与视频 → Kling | 已接入的可灵视频模型 | 使用 Access Key / Secret Key；当前目录需手工维护 |
| 图片与视频 → xAI / Grok | Grok 文生视频、首帧图生视频 | 服务必须实现对应视频协议 |
| 图片与视频 → Meta Muse | 通过自建 muse2api 服务调用视频能力 | 填写自建地址及独立密钥，并非 Meta 官方公开模型 API |
| 配音选择 | Edge TTS 音色、语速与试听 | 在线服务，需要联网，无需上述模型密钥 |
| 网络与调试 | 提供商代理与诊断选项 | Base URL 是服务地址；本地代理是网络转发地址 |

### 从接口加载模型

1. 在对应服务填写 **Base URL** 和密钥；需要代理时填写公共代理地址，并启用该服务的代理开关。
2. 点击 **从接口加载模型**。目录不支持查询的服务，可明确选择 **手动维护** 并应用模型 ID。
3. 保存配置。文本模型还需选定实际使用的型号；创作页面再选择该功能所需模型。
4. 新增型号或更换连接后，重新加载并保存目录。

目录绑定当前地址、凭据和启用的代理配置，重启后仍可读取。文本和视觉模型下拉读取保存的目录；图片、视频、数字人等选项还会与当前已实现的适配能力取交集。**目录里有一个型号，不代表它支持所有输入，也不代表它已经能在每种创作方式中使用。**

### 配了密钥，为什么还不能生成

密钥、模型目录、当前选择是三件事。自定义素材需要先配置视觉服务，再加载目录，并明确选择一个支持图片输入的分析模型。

如果视觉服务已经保存但目录为空，可直接到 **自定义素材 → 画面与配音** 点击 **加载并保存模型列表**，无需重新输入密钥。最后一步会区分缺少配置、缺少目录和未选择型号，并提供返回模型选择的按钮。

“测试连接”只执行只读查询；“加载模型”只获取目录；“保存配置”写入本地；“生成”提交创作任务。图片 / 视频预览也会请求对应模型，配音试听会访问在线语音服务。模型请求可能计费，实际权限、接口支持和输出质量需要按服务确认。

更多细节：[动态模型目录](docs/dynamic-model-catalog.md) · [Grok / Muse 接入](docs/grok-muse-video.md) · [常见问题](docs/frameweave-faq.zh.md)。

## 模板与个性化

模板位于 `templates/`，按画面尺寸组织。选择模板后，可填写该模板提供的标题、作者、品牌、标语等参数；具体字段以所选模板为准。默认品牌为镜织 FrameWeave，也可以改成自己的账号或栏目。

使用 HTML / CSS 调整布局时，应保留模板参数约定，并检查中文字体、长标题换行和画面安全边距。内置模板预览可在本地重建：

```bash
# 只重建模板预览，不调用模型生成接口。
uv run python docs/rebuild_template_previews.py
```

## 开发与项目结构

```text
studio/                   React + TypeScript 工作台、导航与布局
frameweave/               本地服务与统一启动器
web/                      创作表单、步骤导航、配置中心与作品记录
pixelle_video/pipelines/   文案、素材与视频编排管线
pixelle_video/services/    模型适配、视觉分析、配音与合成服务
templates/                HTML 画面模板
tests/                    配置、接口模拟、流程与本地合成测试
docs/                     使用指南、接入说明与开发记录
config.example.yaml       可公开的配置样例
```

前端开发时启动后端，再在另一终端运行 `npm --prefix studio run dev`；正式构建由本地服务读取 `studio/dist`。Python 包及导入路径保留 `pixelle-video` / `pixelle_video`，便于兼容既有配置和模块。历史实验模块仍留在仓库中，但不作为当前工作台功能入口。

```bash
# 安装测试工具并运行本地测试。
uv sync --frozen --extra dev
uv run python -m pytest tests -q

# 检查前端类型并构建。
npm --prefix studio run build
```

现有 GitHub Actions 检查 FrameWeave 核心子集与前端构建；完整创作表单、模型目录等回归使用上面的全量测试命令。测试以模拟接口和本地处理为主，真实供应商生成验证需单独记录。

## 当前边界与反馈

当前版本面向单用户本地使用，默认监听 `127.0.0.1`。模型服务通过 API 调用，模板渲染与成片合成在本机完成。Web 页面使用直接模型 API，不提供 RunningHub / ComfyUI 工作流入口。

尚未提供多人账号、持久项目草稿、自由剪辑时间轴、精准逐字口型同步或整条长视频自动断点续生成。遇到问题时，请附上功能入口、操作步骤、模型名和脱敏报错；不要提交真实密钥、个人素材或本地配置。
