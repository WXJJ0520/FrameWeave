## 验证结果

- Python 回归：**381 项测试、562 个子测试通过，3 项跳过**；保留 29 条既有警告。
- 前端：TypeScript 检查与 Vite 生产构建通过。默认终端 Node 16 会出现 `crypto.getRandomValues is not a function`；使用本机已安装的 Node 24 后通过，没有改变系统默认 Node 设置。
- Markdown：检查 UTF-8、正文中的本地文件链接、站点导航目标及模板图片路径；不把代码块中的示例路径当作真实文件链接。
