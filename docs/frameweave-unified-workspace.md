# 镜织 FrameWeave 统一工作台与启动

<!-- 启动器、创作页面与模型服务职责分开说明，避免将后台服务启动视为生成验收。 -->

镜织由统一工作台和创作服务组成。日常从 `http://127.0.0.1:8765` 进入，使用快速创作、数字人口播、图生视频、自定义素材、动作迁移、作品记录和系统配置。五种创作方式使用相同的三步导航，文案、素材、模型参数与结果按操作顺序呈现。

## 页面与服务如何配合

| 部分 | 作用 |
| --- | --- |
| React 工作台 · 8765 | 功能导航、语言入口、纯白布局与内嵌页面管理 |
| Streamlit 创作服务 · 8501 | 创作表单、上传、模型设置、生成状态和结果 |
| 模型 API | 文案、素材理解、图片或视频生成；使用对应提供商配置 |
| 本地处理 | 素材抽帧、HTML 模板渲染、配音文件处理与 FFmpeg 合成 |

配置保存在本地 `config.yaml`。文本服务与各媒体提供商分别配置，工作台不复制密钥到另一套配置。当前 Web 页面使用直接模型 API，不提供 ComfyUI / RunningHub 工作流入口。

切换已打开的功能页面会保留其当前会话；同一创作页面的上一步 / 下一步也保留输入与上传缓存。刷新、关闭页面或重启服务可能清空草稿。切换语言后，已打开页面会提示是否重载应用新语言。

## 准备与启动

请先按[本地运行说明](../本地运行说明.md)安装 Python 依赖、Playwright Chromium、FFmpeg，并构建前端。在项目根目录运行：

```bash
# 同时准备创作服务与完整工作台。
uv run python -m frameweave
```

Windows 可使用 `start_frameweave.bat`，macOS / Linux 可使用 `bash start_frameweave.sh`。默认打开 [8765 工作台](http://127.0.0.1:8765)；[8501 创作服务](http://127.0.0.1:8501)可独立访问，用于检查创作页面是否正常。

## 启动器怎样处理已有进程

| 当前情况 | 行为 |
| --- | --- |
| 主工作台端口已占用 | 提示使用现有工作台或换端口，不结束其他进程 |
| 8501 存在健康且可确认为本仓库的创作服务 | 复用；退出启动器时保留该服务 |
| 8501 空闲 | 用当前 Python 环境启动本仓库 `web/app.py`，健康检查通过后启动工作台 |
| 8501 被其他程序占用，或进程归属不明确 | 报告冲突并保留已有进程 |
| 本次启动的创作服务退出或等待超时 | 报告失败并清理本次创建的子进程 |
| 正常退出工作台 | 只停止本次创建的创作子服务 |

Windows 子服务隐藏启动，无需再打开一个终端。身份核对使用实际监听进程与脚本路径，不会仅因另一个程序也返回 Streamlit 健康响应就将其复用；本机健康探测不使用环境代理。

Windows 下，使用相对 `web/app.py` 参数启动的旧进程可能无法确认归属。请先保存当前工作，正常退出旧启动终端，再运行统一启动命令。不要直接结束不确定归属的进程。

设置环境变量 `FRAMEWEAVE_PORT` 可更改工作台端口；创作服务端口固定为 `8501`，两者不能相同。

## 配置更新与排查

保存 API 设置后，创作页面下一次交互重绘时会检查配置摘要并更新服务实例。仅切换外层导航不会强制重载已有页面；可以在保留草稿的前提下使用上一步 / 下一步触发重绘。不要把刷新整页作为第一步排查方式。

素材分析需要对应视觉服务的目录和明确的模型选择；已填密钥但没有目录时，可在自定义素材第二步直接加载并保存。详情见[动态模型目录](dynamic-model-catalog.md)。

`tests/frameweave_launcher_test.py` 使用模拟网络与子进程覆盖复用、归属校验、端口冲突、超时和退出清理。启动器检查与本地页面可访问不等于供应商生成成功；模型调用需要独立配置并由生成按钮提交。
