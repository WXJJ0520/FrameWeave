# 镜织常见问题

<!-- 当前 Web 使用范围；工作流兼容教程不作为此页的操作步骤。 -->

## 先用哪个功能？

只有主题或完整稿件时使用**快速创作**；已有实拍、录屏或图片时使用**自定义素材**。人物口播、单张图片动画和参考动作编辑分别使用数字人口播、图生视频、动作迁移。

## 要把所有平台的密钥都填上吗？

不用。系统配置中的“按功能找配置”会说明用途，填写本次实际使用的服务即可。文本模型负责脚本、标题和提示词；图片与视频服务负责画面，也提供相应视觉分析能力。OpenAI 媒体配置不会自动复用文本模型的密钥。

## 为什么填好密钥后仍没有模型？

填写 Base URL 与密钥后，需要**从接口加载模型并保存**。目录与地址、凭据和启用的代理配置绑定，更换连接后要重新加载。服务不提供目录接口时，可明确选择手动维护并应用模型 ID。

创作页还会按已适配能力筛选目录。普通文本、审查或音频模型不能直接用于视觉理解；普通文生视频模型也不能充当数字人或动作迁移接口。加载成功不等于生成权限已验证。

## 中转 API 能用吗？

可以接入满足对应协议的服务。地址和密钥应来自同一服务商；OpenAI 兼容文本接口并不自动支持图片或视频请求。Grok、Muse、DashScope 等调用仍需要服务支持各自实现的任务、查询和结果协议。Muse 对应自行部署的第三方 muse2api 服务，并非 Meta 官方公开模型 API。

## 需要安装 ComfyUI 或配置 RunningHub 吗？

当前 Web 工作台使用直接模型 API，不需要这两类工作流服务。旧文档和配置字段只为兼容与历史追溯保留，不是当前页面的操作入口。FFmpeg、Chromium、模板渲染与素材处理仍在本机执行。

## 配音需要什么？能离线用或克隆声音吗？

配音使用 **Edge TTS 在线接口**，可以选择音色、语速并试听，需要联网，不需要填写模型 API 密钥。当前配音入口不提供工作流声音克隆。数字人支持的声音输入由所选视频 API 决定；参考声音不代表精确音轨驱动或逐字口型同步。

## 数字人口播支持多长？Grok / Muse 可以代替吗？

数字人按所选模型的单段时长生成，不属于 5–10 分钟长片入口。当前 Wan 参考声音能力不能保证逐字复现或精确唇形同步。当前 Grok / Muse 接入只用于文生视频和首帧图生视频，不替代数字人或动作迁移能力。

## 怎样生成 5–10 分钟视频？

在快速创作或自定义素材选择 **5 / 8 / 10 分钟**目标。系统规划章节与镜头，再完成旁白、画面与合成。实际长度受稿件、音色和语速影响，完成后会检测时长。单次模型视频上限不会因此改变；长片也尚无自动断点续生成。

## 自定义素材如何理解视频？

支持 OpenAI 兼容视觉接口与 DashScope。视频在本机均匀采样最多 **8 / 16 / 32 帧**，附时间信息后发送给视觉模型，不上传完整视频做分析。采样可能漏掉短暂动作，不识别原音轨；长片合成的均匀取段也不是逐镜头语义定位。

当前单视频上传上限为 **1 GB**；视觉分析图片限制为 **32 MB / 6400 万像素**并会预处理。成片使用生成旁白与所选背景音乐，不混入原素材音轨。

## 切换页面会丢输入吗？

前后切步、切换已经打开的工具页会保留当前会话内容。刷新、关闭页面、重启服务或重新载入以应用语言变化，可能清空输入。会话草稿不是持久项目存档，重要稿件请另行保存。

## 连接测试、保存配置和生成有什么区别？

测试使用当前输入查询接口；保存才写入配置；生成提交创作任务。图片或视频预览也会调用对应模型，配音试听需要联网，并非只有最终生成按钮才调用服务。

保存后先在创作页使用上一步 / 下一步或其他交互触发重绘以读取新配置。只有仍需整页刷新时再操作，并先保存重要稿件，因为刷新可能清空会话草稿。连接测试或模型目录成功，不保证生成权限、余额、协议和模型输入都正确。

## 作品在哪里？出错后要重新生成吗？

成片在创作页预览、下载，也可在作品记录中查找。若提示视频已生成但记录或展示失败，先找已有结果；不要把记录失败直接当成生成失败重复提交。其他问题见[故障排查](troubleshooting.md)。
