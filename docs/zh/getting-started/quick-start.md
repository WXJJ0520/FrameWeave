# 镜织 FrameWeave 快速开始

<!-- 以当前五种创作入口和逐步操作为准，不承诺固定耗时或生成效果。 -->

先完成 [安装](installation.md) 与 [模型配置](configuration.md)。在项目根目录启动：

```bash
uv run --frozen python -m frameweave
```

打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。默认中文，右上角可切换 English。五个创作入口都采用“准备内容 → 设置参数 → 预览与生成”的逐步方式，点击底部“上一步 / 下一步”操作。

## 做第一条快速创作短片

### 第一步：准备内容

进入 **快速创作**，选择 AI 创作或自行创作：

- **AI 创作**：输入主题、讲解要求和可选标题。例如“用三个生活例子解释 AI 幻觉，面向第一次使用 AI 的人，语气简洁”。
- **自行创作**：输入完整旁白，保留自己的原稿；长段落会按镜头需要拆分。

首次测试使用少量镜头即可。批量模式按每行一个主题逐条制作短片，不用于批量导入完整稿件。

### 第二步：设置画面与配音

1. 选择模板和画面类型，检查模板决定的画幅与媒体尺寸。
2. 选择对应的图片或视频 API 型号。无模型时回系统配置加载并保存目录。
3. 设置画面风格、提示词前缀以及模型已经提供的参数。
4. 选择 Edge TTS 音色、语速，可先试听短文本；按需选择背景音乐及音量。
5. 模板提供作者、签名、品牌等自定义字段时，填写自己的栏目名称。

图片模板生成配图，视频模板生成多个短镜头。模板参数用于版面，不会自动改变模型的原生输出限制。时长、分辨率和画幅选项随具体适配器变化。

### 第三步：确认并生成

确认内容、模型和输出设置，再点击生成。系统执行文案处理、配音、画面制作、模板渲染及合成。耗时由镜头数、服务排队和网络决定，不保证固定分钟数完成。

完成后在当前页面预览、下载成片，可到 **作品记录** 查找生成记录。输出保存在 `output/`。目录或连接测试成功不等于整条生成链路已验证。

## 用自己的素材制作解说

进入 **自定义素材**：

1. 上传图片、实拍或录屏视频，填写标题和“内容方向与讲解要求”。
2. 选择 OpenAI / 兼容接口或通义作为视觉服务，明确选择支持图片输入的模型。已配置密钥但缺目录时，点击 **加载并保存模型列表**。
3. 设置短片目标 15–120 秒，或长片目标 5 / 8 / 10 分钟；选择配音与背景音乐。
4. 选择视频抽帧上限 8 / 16 / 32 帧。更多帧会增加请求体积，仍不能保证识别短暂动作。
5. 在最后一步检查素材与预算，再生成。

默认使用原图片与视频合成；主动启用素材动画后，匹配到的图片会额外调用图生视频 API。视频单文件上传上限 1 GB，视觉分析图片限 32 MB / 6400 万像素。视频在本机抽帧后分析，不发送整段视频做视觉分析。

## 制作 5–10 分钟长片

快速创作和自定义素材都有长视频选项。选择 5、8 或 10 分钟目标及旁白语言，再检查章节、镜头、文案与素材预算。系统分章处理内容，逐镜头配音并制作画面，最终合成完整长片。

目标是规划值，成片后会检查实际时长；自行创作不会补写或重复原稿凑时长。视频模型仍生成各自支持的短片段。素材不足时可能复用或循环，均匀取段不等于按旁白精准定位动作。素材原音轨不识别、不保留到成片，使用生成旁白与背景音乐。

先确认短片流程能完成，再扩大镜头数量。当前不支持失败后自动断点续生成。

## 其他三种创作方式

| 入口 | 准备内容 | 使用边界 |
| --- | --- | --- |
| 数字人口播 | 人物图片、口播文案、音色与模型 | 先合成参考配音，再调用同时支持人物图片和参考声音的接口；当前无直接上传口播音频入口 |
| 图生视频 | 图片、动作和镜头提示词 | 当前生成使用第一张上传图片，按模型单次时长输出 |
| 动作迁移 | 人物图片、参考动作视频、提示词 | 当前使用第一张人物图片和第一段参考视频，需要相应视频编辑能力 |

Wan 的参考声音不保证逐字复现或精准口型同步。Grok / Muse 的普通视频能力不替代数字人或动作迁移能力。

## 输入保留与常见问题

切换步骤和已打开的功能页保留当前会话输入；刷新、关闭页面或重启服务可能丢失草稿。配置保存后可先切换步骤更新，无需立即刷新整页。

- 模型下拉为空：检查正确提供商的目录是否已加载保存，以及是否适配当前页面。
- 素材第三步被拦截：返回第二步补齐视觉服务目录，并明确选择型号。
- 配音失败：先做 Edge TTS 短文本试听，检查网络和运行依赖。
- 模板无法渲染：检查 Playwright Chromium、FFmpeg 与中文字体。
