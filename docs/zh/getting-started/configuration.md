# 镜织 FrameWeave 模型与 API 配置

<!-- 字段用途和目录来源以当前设置页及适配器为准，不以名称推断供应商能力。 -->

打开工作台右上角 **系统配置**。配置分为 **文本模型、图片与视频、网络与调试**，顶部“按功能找配置”可帮助找到对应字段。只配置自己要用的服务即可。

## 按用途选择配置

| 要完成的任务 | 配置位置 | 说明 |
| --- | --- | --- |
| 脚本、章节、标题、素材解说、画面提示词 | 文本模型 | 使用 OpenAI 兼容文本接口，与媒体凭据独立 |
| GPT 图片与 OpenAI 兼容视觉分析 | 图片与视频 → OpenAI | 图片生成与素材理解共享这组媒体凭据 |
| 通义图片、视频、视觉分析 | 图片与视频 → 通义 | 数字人及动作迁移还需选已适配相应能力的型号 |
| Grok 视频 | 图片与视频 → Grok | 快速创作镜头、图生视频；不承担素材视觉分析 |
| Muse 视频 | 图片与视频 → Muse | 调用你自建的 muse2api 服务 |
| Seedream 图片、Seedance 视频 | 图片与视频 → 火山 | 使用 ARK 凭据，当前手动维护模型目录 |
| 可灵视频 | 图片与视频 → 可灵 | 使用 Access Key 与 Secret Key，当前手动维护目录 |
| 配音 | 各创作页的配音设置 | Edge TTS 无需 API 密钥，但需要联网 |

“同一个中转站”不代表配置自动互通：文本、OpenAI、Grok、Muse 等分别保存各自地址和凭据。不要将文本服务目录当作视觉服务目录。

## 配置文本模型

1. 打开 **文本模型**，选择服务预设或自定义服务，填写 Base URL 和 API Key。
2. 预设用于辅助填写服务地址，不代表已经获取账号可用型号。
3. 点击 **从接口加载模型**，在目录选择模式中选一个实际可用的文本模型。
4. 若使用中转别名或不提供目录的接口，可以选择独立的 **自定义模型** 输入方式，填写服务支持的精确 ID；它不会冒充接口返回的下拉选项。
5. 点击页面底部 **保存配置**。

文本服务需要实现 OpenAI 兼容的聊天请求协议；模型名称相同不保证不同中转站行为相同。已有自定义型号会保留，不会仅因刷新目录而自动改成另一型号。

## 配置图片、视频与视觉服务

在 **图片与视频** 中选择对应提供商，填写自己的基础地址及密钥。通常填写 API 根地址，例如带有服务规定版本前缀的地址，不要填 `/models`、`/images/generations` 或 `/videos/generations` 这样的具体端点。

| 设置平台 | 目录方式 | 注意事项 |
| --- | --- | --- |
| OpenAI | 从接口加载 | 也可使用支持相应协议的兼容站 |
| 通义 / DashScope | 从接口加载 | 支持原生目录；使用兼容接口时保留服务规定的路径 |
| Grok / xAI | 从接口加载 | 目录查询成功仍不代表视频任务接口可用 |
| Muse | 从接口加载 | 填自建 muse2api 地址和该服务密钥 |
| 火山 / ARK | 手动维护 | 当前未接入目录查询 |
| 可灵 / Kling | 手动维护 | 当前未接入目录查询，需两项凭据 |

接口加载成功后，点击 **保存配置** 才供其他创作页使用。手工目录每行一个真实模型 ID，先点 **应用手动目录** 再保存；页面会标明“手动维护，未验证”。旧 `vision_models` 字段仅为历史值，不自动成为可用目录。

图片与视频下拉显示 **已保存目录和当前适配能力的交集**。向目录加入未知视频型号不会自动实现任务提交、轮询和下载协议；数字人、动作迁移还会进一步检查所需输入能力。

## 自定义素材的视觉分析

支持 OpenAI / 兼容视觉 API 和 DashScope / Qwen。请使用支持**图片输入**的模型；纯文本、语音或图片生成模型不能仅因出现在目录中就承担素材理解。

1. 在 OpenAI 或通义平台保存地址、密钥及目录。
2. 回到 **自定义素材第二步**，选择对应视觉服务与型号。
3. 已保存服务配置但缺目录时，直接点击该页 **加载并保存模型列表**，然后明确选择视觉型号。

这个素材页按钮只查询模型名称，直接保存所选服务目录，不上传素材、不调用生成模型。它与设置页“加载后仍需统一保存”的行为不同。

若第三步提示缺少目录，返回第二步补齐；若提示未选模型，在第二步明确点选。列表为空时检查账号权限、查询响应或改为明确的手工目录，不会自动回退固定型号。

## 代理与连接检查

在 **网络与调试 → 本地代理** 填写媒体请求所用代理地址，然后在对应提供商勾选 **启用代理**。未启用的媒体服务不使用这项设置；它不是文本模型的统一代理开关。

本机运行时，`127.0.0.1` 指自己的电脑。远程中转服务应填写该服务的真实地址。Base URL、密钥和代理路由需要匹配。

**测试连接**使用当前表单输入查询服务，不保存、不生成。测试通过只证明被查询接口可达，不能证明图片输入、付费生成或视频下载已经验证。

## 保存、生效与失效

- 配置保存在项目根目录 `config.yaml`，不存在时首次保存会创建。
- 目录记录来源、加载时间及连接指纹。地址、凭据或启用的代理变更后，必须重新加载或明确应用手工目录。
- 设置页刷新目录失败或返回空列表会清空当前候选；保存后不继续使用旧目录或内置型号。
- 在素材页直接加载失败时不会写入新的目录；只有查询与本地保存都成功，才报告已保存。
- 保存后创作页下一次交互会刷新服务配置，可先切换步骤；无需为了更新配置立即刷新整页。
- 已打开的设置页会同步同连接下其他页面保存的新目录；如果本页有未保存的目录操作，会提示冲突并保留本页草稿。

密钥属于本地配置，不应提交进仓库或贴进公开问题。当前应用面向单用户本地使用。
