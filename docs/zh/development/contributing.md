## 如何贡献

1. Fork 项目仓库
2. 创建功能分支 (`git checkout -b feature/AmazingFeature`)
3. 提交更改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 开启 Pull Request

## 开发设置

```bash
# 克隆你的 fork
git clone https://github.com/your-username/Pixelle-Video.git
cd Pixelle-Video

# 安装开发依赖
uv sync

# 运行测试
pytest
```
