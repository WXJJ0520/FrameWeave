# 镜织故障排查

<!-- 先定位实际失败环节，不把状态码、模型目录或历史测试当作完整生成结论。 -->

先看错误发生在启动、模型查询、素材分析、配音、视频生成还是合成阶段。相同状态码可能有不同原因，按当前服务检查，不直接替换为其他平台的密钥。

## 工作台无法打开

| 现象 | 检查方式 |
| --- | --- |
| 找不到前端页面或提示缺少构建 | 在项目根目录完成 `npm --prefix studio ci` 和 `npm --prefix studio run build` |
| 构建报 `crypto.getRandomValues is not a function` | 先用 `node --version` 检查实际执行版本，使用文档推荐的 Node.js 22；旧版 Node 16 不满足当前构建要求 |
| 8765 被占用 | 查看已有服务；需要时用 `FRAMEWEAVE_PORT` 选择其他主端口，不能与 8501 相同 |
| 8501 已被占用或无法确认进程归属 | 保留现有进程，确认是否为本仓库服务；旧启动终端正常退出后再运行统一启动器 |
| 内嵌创作页连接失败 | 单独打开本机 8501 检查；确认创作服务已启动，再重新载入对应工具页 |
| Python 依赖缺失 | 使用项目环境执行 `uv sync --frozen`，不要混用其他 Python 环境 |

正常启动入口为 `uv run python -m frameweave`，主页面在 [127.0.0.1:8765](http://127.0.0.1:8765)。不需要另外启动 ComfyUI 或 RunningHub 工作流。

## 地址、密钥与模型目录

- **401 / 403**：核对所选提供商凭据、账户权限、反代鉴权和模型权限。不要把其他配置组的密钥直接套用。
- **404**：检查 Base URL 与服务实现的路径。只有同属 OpenAI 兼容协议时，相关路径约定才可复用；不要给所有服务统一追加 `/v1`。
- **502 / 503 / 504**：检查中转站或反代上游状态；仅凭状态码不能认定密钥错误。
- **连接或读取超时**：检查地址、网络与所选代理是否可达；模型生成时还需区分提交、等待任务与获取结果。
- **模型目录为空或失效**：修改地址、密钥、代理后重新加载并保存。服务不提供目录接口时使用明确的手动维护方式。

目录查询成功不等于有生成权限。某型号出现在接口中但未显示在视频或数字人列表时，可能尚未适配对应任务和输入，不应绕过能力限制硬填。

## 自定义素材提示未配置或未选择模型

在“图片与视频 → OpenAI / 通义”配置实际使用的视觉服务，加载保存目录，再回素材页选择服务商和明确型号。已经配置服务但没有目录时，也可在素材页第 2 步点击“加载并保存”；第 3 步的提示可带你返回模型选择。视觉分析不自动复用文本模型密钥。

保存后先用上一步 / 下一步或下次页面交互触发重绘，读取新配置。仍需整页刷新时先保存重要稿件；刷新可能清空会话草稿。

模型必须支持图片输入。视频分析使用抽帧，增加 8 / 16 / 32 帧上限可以增加覆盖范围，但不保证识别短暂动作，也不会识别原音轨。上传视频上限为 1 GB；视觉分析图片超过 32 MB 或 6400 万像素时，先缩小原图。

## 配音失败或 Edge TTS 返回 403

Edge TTS 是在线服务，即使合成在本机发起也需要联网。先更新项目锁定依赖、正常重启运行环境，再独立试听当前音色。此阶段不使用 Grok 或 OpenAI 密钥；403 不应通过更换这些密钥解决。

若在线服务持续拒绝或超时，保留错误阶段与状态信息，检查网络和服务可用性。当前 Web 不会回退到旧 TTS 工作流。

## 数字人或视频生成失败

1. 确认模型支持本次人物图、音频或参考视频输入；Grok / Muse 不替代数字人和动作迁移能力。
2. 检查当前模型允许的时长、画幅、分辨率和素材格式。
3. 若任务已经提交但未返回有效视频，结合任务 ID 检查提供商状态，避免直接重复提交产生额外调用。
4. 若提示仅作品记录或展示失败，先检查已生成文件和现有结果。

参考声音不保证逐字口型同步。中转站能查询模型或生成文本，也不代表实现了所选视频协议。

## 模板、字幕或合成失败

- 在启动应用的同一环境执行 `ffmpeg -version`、`ffprobe -version`，确认它们在 `PATH` 中。
- 模板渲染缺少浏览器时，执行 `uv run playwright install chromium`；Linux 可按[安装指南](getting-started/installation.md)补系统依赖。
- 中文字幕缺字时安装支持中文的字体，例如 `fonts-noto-cjk`，再正常重启相关进程。
- 检查输出位置可写、磁盘空间充足，素材文件仍存在。

## 长视频长度不符或素材重复

目标分钟数是脚本预算，不是严格秒数承诺。核对语速、完整稿件长度和实际时长提示。素材不足可能复用，短片段可能循环；快速创作短于旁白的视频可能停留末帧。自定义素材按时间取段，尚未实现逐句语义定位。

长片目前不能从失败处自动续生成。先用短片确认服务和参数，再扩大镜头数。

## 提交问题时保留什么？

记录使用入口、失败阶段、错误状态、所选模型、应用版本或提交，以及不含敏感信息的最小复现步骤。移除密钥、完整鉴权网址和私人素材后再分享日志。不要将镜织特有问题直接当成上游已确认缺陷。
