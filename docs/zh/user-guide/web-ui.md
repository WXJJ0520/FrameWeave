# 镜织工作台使用指南

<!-- 操作说明对应当前三步页面，区分会话草稿、配置保存和真实生成。 -->

镜织默认打开快速创作。导航中还可切换数字人口播、图生视频、自定义素材、动作迁移、作品记录与系统配置。界面以中文为主，右上角可以切换 English。

## 三步完成创作

| 步骤 | 做什么 | 何时调用生成服务 |
| --- | --- | --- |
| 内容与素材 | 输入主题、完整稿件，或上传当前任务需要的图片和视频 | 上传素材本身不会自动提交视频生成 |
| 画面与参数 | 选择模型、时长、画幅、模板、配音与背景音乐；具体参数按功能显示 | 明确点击试听或模型预览时，会调用对应服务 |
| 预览与生成 | 检查输入与预算，点击生成，查看进度和结果 | 点击生成后才提交创作任务 |

使用页面底部“上一步 / 下一步”切换。返回前一步可以继续修改；最后一步的摘要用于确认本次提交内容。已生成结果和最近批量统计可在当前会话返回查看。

## 五种创作方式

### 快速创作

- **AI 创作**：输入主题和可选标题，模型组织文案与画面提示词。
- **自行创作**：使用完整原稿，按需要拆分段落，不补写或重复来凑时长。
- **画面选择**：图片模板使用配图，视频模板生成多个短镜头；静态模板不需要生成画面。
- **配音与音乐**：选择 Edge TTS 音色、语速和背景音乐，试听是一次独立的在线请求。
- **长视频**：选择 5 / 8 / 10 分钟，检查章节、镜头和字数预算。批量创作保持独立流程，不等同长视频模式。

### 数字人口播

上传人物图片并填写口播文案，配音使用在线 Edge TTS，视频请求使用人物首图与合成的参考声音。参数按实际 API 能力展示。当前入口没有直接上传口播音频的选项；参考音色不保证逐字复现或精确唇形同步，生成时长仍受单段模型限制。

### 图生视频

上传首帧图片，描述动作、镜头与画面风格，选择视频模型以及它支持的时长、画幅、分辨率等参数。不同服务的控制项不完全相同。

### 自定义素材

上传图片、实拍或录屏，填写标题和“内容方向与讲解要求”。第 2 步选择 OpenAI 兼容视觉或 DashScope 服务、明确的视觉模型、目标时长与配音。短片目标为 15–120 秒，长片为 5 / 8 / 10 分钟。

视频在本机均匀抽取最多 8 / 16 / 32 帧供分析，不识别原音轨。默认以原素材合成；开启素材动画才为匹配的图片调用图生视频 API。长片会按时间均匀取段，素材不足可能复用或循环，不能保证语义精确定位到某个动作。

### 动作迁移

上传人物图片和参考动作视频，填写动作或编辑要求，选择已适配的视频编辑 API。普通文生或首帧图生模型不自动支持此功能。

## 系统配置按用途分组

| 配置分组 | 用途 |
| --- | --- |
| 文本模型 | 脚本、章节、素材旁白、标题与画面提示词 |
| 图片与视频 | 图片、视频、数字人与动作能力，以及素材视觉分析 |
| 网络与调试 | 公共代理、各服务代理开关与诊断选项 |

先查看“按功能找配置”，再填写需要的平台。地址、密钥与模型来自同一服务；不同配置组不会自动借用文本密钥。

填写连接后点击“从接口加载模型”并保存。不提供目录接口时，明确使用手动维护。修改地址、凭据或启用的代理后目录会失效，需要重新加载。目录中的型号还会按当前功能已适配的能力筛选。详见[配置指南](../getting-started/configuration.md)。

连接测试查询当前输入，保存才写入配置，生成则提交任务。这三种操作有不同目的；图片 / 视频预览也调用模型，配音试听也需要联网。保存后先通过创作页上一步 / 下一步或其他交互触发重绘。必要时才整页刷新，并先保存重要稿件，避免丢失会话草稿。

## 预览、下载与作品记录

生成过程中显示当前阶段，完成后可预览、下载，并在作品记录中查询。失败提示会尽可能标明实际阶段；若视频已生成而记录保存失败，应先检查现有结果，避免重复提交。

历史记录与会话草稿是不同内容。切换已打开的工具页和步骤通常保留当前输入；刷新、关闭、重启或重新载入应用语言后可能清空草稿。重要文案与原素材应另行保存。

## 时长与费用预期

长视频目标是规划预算，完成后会探测实际长度。镜头越多，处理时间和模型调用量通常越大；当前没有整条长片失败后的自动续生成。连接测试、离线测试或成功加载模型目录，都不能替代真实生成验证。

需要排查时查看[故障排查](../troubleshooting.md)或[常见问题](../faq.md)。
