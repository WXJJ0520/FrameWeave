# 镜织 FrameWeave 功能状态与开发方向

<!-- 已实现能力与后续计划明确分开，避免将路线图当作可用功能承诺。 -->

镜织围绕“把主题或自有素材制作成完整视频”组织功能。当前以五种创作方式、统一步骤、按用途配置模型和本地合成为主，详细使用说明见[产品 README](../README.md)。

## 已实现的产品能力

| 模块 | 当前能力 |
| --- | --- |
| 快速创作 | 主题文案、自行创作、按主题批量短片、配图或视频模板、配音与背景音乐 |
| 数字人口播 | 人物图片、文案合成参考声音、适配 API 生成；参考声音不保证逐字口型同步 |
| 图生视频 | 首张参考图、动作提示词、按模型展示时长和输出参数 |
| 自定义素材 | 图片 / 视频上传、OpenAI 兼容或通义视觉分析、解说生成、素材匹配与合成 |
| 动作迁移 | 首张人物图与首段参考动作视频、匹配的视频编辑 API |
| 长视频 | 快速创作和自定义素材的 5 / 8 / 10 分钟规划、章节与旁白校验、实际时长检测 |
| 模型配置 | 分提供商配置、动态模型目录、明确手工目录、只读连接测试、配置用途说明 |
| 创作体验 | 三步导航、会话内输入保留、纯白工作台、中文 / English 切换、作品记录 |

模型目录只证明接口返回该名称。页面是否可以使用，还取决于适配器是否实现所需输入、参数和任务协议；账户权限及真实生成效果单独验证。

## 后续优化方向

以下为计划方向，尚不能作为现有功能使用：

1. **生成前检查更完整。** 让素材、模型能力、网络和输出参数的问题尽量在提交前暴露，减少等待后失败。
2. **长片失败恢复。** 记录已经完成的旁白与画面步骤，设计可恢复任务，避免整条视频重复请求；需明确供应商任务状态与重复计费边界。
3. **素材匹配更准确。** 从目前的描述匹配和均匀取段，逐步增强时间段定位、重复素材提示及可解释的片段选择。
4. **配置与能力映射。** 继续完善服务目录、实际协议和功能入口的对应关系，减少模型已列出但能力不匹配的情况。
5. **结果与错误反馈。** 将生成结果、下载失败、合成失败和记录写入问题分开呈现，提供与实际阶段一致的恢复指引。
6. **布局与双语一致性。** 检查窄屏、长标题、模型列表、状态提示和中文字体，保持五种创作页面统一。

当前没有把独立分镜编辑器、项目版本系统或自由剪辑时间轴列为工作台功能。仓库中的实验代码与验收记录用于追溯实现，不代表产品入口已经开放。

## 验证方式

每次改动区分代码检查、模拟接口测试、本地媒体合成、浏览器交互和真实供应商调用。离线测试通过不能替代模型生成验收；带日期记录只描述当次验证范围。

不把私有配置、密钥、个人素材或生成结果提交到仓库。发行包、远程仓库与 Release 以实际发布为准，不使用其他项目的下载页充当镜织发行页。
