# Pixelle Studio 界面改版

> 此文保留此前独立 Streamlit 改版记录。当前工作台已改为纯白主题和五页统一步骤，见 [最新步骤验收](creation-flow-validation-2026-10-21.md)；下文旧标签页及工作流设置不再代表当前界面。

本次在原有 Streamlit 应用内调整界面，不改变视频服务协议及模型凭据。

- 统一深色主题、青绿色强调色、字体与间距；样式入口为 `web/assets/studio.css`，原生控件主题位于 `.streamlit/config.toml`。
- 公共导航、顶部栏和创作引导由 `web/components/studio.py` 与 `header.py` 提供，首页和历史页共用。
- 快速创作分成脚本、画面与配音两个标签；宽屏显示编辑与预览两栏，窄屏自动堆叠。
- 预览区显示真实表单概览。成功生成后仅缓存本地文件路径和必要元数据，普通重绘、下载或语言切换不会再次调用生成。
- 语言切换使用回调更新，脚本控件保持稳定标识，保护已输入的稿件。
- 新会话默认中文，右上角并排提供“中文 / English”切换；工作台标题、引导和侧栏说明随选择同步，保留手动选择。
- 系统配置从首页展开区移到右上角“设置”弹窗，按文本模型、图片与视频、工作流、网络与调试分组；媒体服务再按六家提供商分页显示。
- 设置草稿只保存在当前会话，关闭不会写入配置；明确保存后清理草稿并关闭。弹窗在主页面表单全部渲染后打开，避免保存重绘清空创作稿件。
- 本地工作流的调试说明改为就地折叠内容，避免隐藏标签里的浏览器弹窗打断操作。
- 动效仅用于入场与悬停，尊重系统的 `prefers-reduced-motion` 设置；不依赖外部字体或脚本。

## 本地验证

新增 `studio_ui_test.py`、`settings_dialog_test.py` 和 `selfhost_warning_ui_test.py`，使用隔离配置与模拟生成测试语言切换、草稿保留、预览缓存、输入校验、设置弹窗保存及关闭和工作流说明。已检查本地宽屏、窄屏渲染；没有提交真实音频或视频生成。

修改主题配置后重启本地 Streamlit 服务即可；修改 Python 页面后可使用页面的 Rerun 重绘。
