# 镜织 FrameWeave：Grok 与 Meta Muse 视频接入

<!-- 接入说明描述当前代码支持的协议；目录查询不等于生成能力验收。 -->
从[镜织工作台](http://127.0.0.1:8765)进入系统配置，在「图片与视频」填写对应服务的地址、密钥，加载模型目录并保存，再回到创作页面选择模型。当前页面直接使用 API，不需要切换工作流来源。独立[创作页面](http://127.0.0.1:8501)也可用于排查问题。

## Grok

- 配置区：**xAI / Grok Imagine Video**。
- 官方 Base URL：`https://api.x.ai/v1`；API Key 填该服务对应的密钥。
- 模型：`grok-imagine-video-1.5`、`grok-imagine-video-1.5-lite`、`grok-imagine-video`。
- 已接入文生视频、首帧图生视频、1–15 秒时长、画幅、分辨率和原生音频开关。
- 经典模型支持 480p / 720p；1.5 支持原生 1080p，1.5-lite 的 1080p 为升采样。
- 图生视频的画幅跟随首帧图片。快捷创作默认关闭模型音频，以便使用自己的旁白。

若使用中转站，地址必须实现 xAI 的视频协议：`POST /v1/videos/generations` 和 `GET /v1/videos/{request_id}`。仅支持 OpenAI 聊天接口不代表支持此视频协议。

支持中转返回相对视频地址，例如 `/v1/videos/<任务ID>/content`：客户端会基于服务地址补全。只有与所配置 API 完全同源的首个下载请求携带密钥，外部媒体地址和重定向后的请求不携带 API 密钥。任务已经完成但下载失败时，可用客户端 `resume_video(request_id, save_path)` 继续查询和下载原任务，不重新提交生成。

## Meta Muse / muse2api

- 配置区：**Meta Muse / muse2api**。
- Base URL 填你另一台服务器的外部访问地址，例如 `https://your-muse-server/v1`。
- API Key 填自建服务的 `MUSE2API_KEY`。
- 模型选择 `muse-video`，已接入文生视频与首帧图生视频。
- 可请求 5 / 6 / 8 / 10 秒、16:9 / 9:16；最终长度由上游决定，下载后使用 FFprobe 读取实际长度。
- 当前未提供分辨率与音频开关，页面不会显示这些无效参数。

接入协议依据用户指定的 [muse2api 项目](https://github.com/czg86389-hub/muse2api)，不是 Meta 官方 Model API。客户端提交 `POST /v1/videos`，按任务 ID 轮询 `GET /v1/videos/{id}`，完成后下载成片到本地。服务器须正确配置对外媒体地址（`MUSE2API_PUBLIC_BASE`），本机需能访问返回的视频地址。

## 使用与验证范围

「快速创作」的视频模式与「图生视频」页面都可选择这两类模型；列表来自已保存目录与已接入能力的交集。只填写密钥或只通过连接测试，尚不足以让模型出现在创作下拉中。

两套凭据独立保存，不复用 OpenAI 配置。可选环境变量为 `XAI_API_KEY` / `XAI_BASE_URL`、`MUSE_API_KEY` / `MUSE_BASE_URL`。如需网络代理，在公共代理地址中填写，再勾选对应供应商的代理开关。

每个媒体服务的配置下方都有「测试连接」按钮。它使用页面当前填写的地址、密钥和代理，无需先保存；只查询模型目录或视频任务列表，不提交生成任务。结果显示响应耗时、HTTP 状态和必要的错误提示。修改输入后，旧测试结果会自动清除。

连接检查使用显式代理配置：不勾选对应服务的「启用代理」时直接连接，不继承 Windows 系统代理。浏览器能打开中转站，不代表程序直连一定稳定。若直连超时，可在「本地代理」填写已运行的 HTTP 代理地址，再勾选 OpenAI 或 xAI 的代理开关，测试成功后保存。代理端口以本机软件实际设置为准；中转站的 Base URL 与本地代理是两个不同地址。

诊断等待时间为建立连接 10 秒、读取响应 20 秒，并区分连接超时、响应读取超时及流读取超时。超时本身不能判断密钥错误；HTTP 401 通常需要检查密钥，404 则需要核对中转实现的接口路径。不要为解决超时关闭 HTTPS 证书验证。

Grok 优先查询专用视频模型目录；若中转不支持，会在同一服务地址下尝试通用模型目录。只返回聊天模型时会提示尚未确认视频模型。测试成功也不代表实际生成、余额或 Muse 上游账号有效，这些仍需生成时验证。OpenAI、百炼、ARK 与 Kling 同样提供对应的只读连接检查。

提交失败、审核拒绝和任务超时不会自动重建生成任务。若提示已有任务 ID，应先检查服务端任务，避免重复提交。

验证覆盖本地模拟响应、页面操作，以及用户指定中转的真实只读模型查询；没有提交真实图像或视频生成任务。模型列表可达不代表生成接口协议、额度和最终生成效果已经验证。

协议依据：[Grok 视频文档](https://docs.x.ai/developers/model-capabilities/video/generation)、[muse2api 源码](https://github.com/czg86389-hub/muse2api/blob/main/app.py)。
