# 五类创作页统一步骤验收

<!-- 本记录仅针对 2026-10-21 的步骤布局改动，不代表外部模型的在线可用性。 -->

本轮把原有五个创作页整理为连续步骤，没有新增分镜编辑器或改变 API-only 业务范围。

| 页面 | 第 1 步 | 第 2 步 | 第 3 步 |
| --- | --- | --- | --- |
| 快速创作 | 视频脚本，支持单条与批量 | 画面模板、模型、配音、背景音乐 | 预览与生成 |
| 数字人口播 | 人物、模式、商品素材或口播文案 | 口播 API 模型与配音 | 预览与生成 |
| 图生视频 | 图片与提示词 | API 视频参数 | 预览与生成 |
| 自定义素材 | 素材、标题与创作方向 | 分析、动画、时长、配音、背景音乐 | 预览与生成 |
| 动作迁移 | 人物图片、参考动作视频与提示词 | 支持动作迁移的 API 参数 | 预览与生成 |

## 状态与交互

- 统一步骤进度、卡片、说明、底部导航。首步禁用“上一步”，末步不显示“下一步”。
- 输入步骤持续挂载，非当前步骤通过 CSS 隐藏，避免 Streamlit 清理文本、选项及上传控件状态。
- 上传内容按名称与内容摘要缓存，各流程及素材角色隔离；重复导航不重复写文件，同名替换仍更新路径。
- 最终生成区域仅在末步呈现。输入及 API 能力校验沿用原流程，导航不会提交生成。
- 生成失败或输入校验失败后保留返回导航。已有成片和批量结果可以返回查看，不自动重新调用服务。
- 批量结果保留统计、耗时、失败任务序号与主题；不把原始第三方异常和堆栈写入新增会话摘要。
- 语言按执行上下文隔离，避免中文与英文 iframe 并发重绘时相互覆盖。
- 嵌入页发送步骤导航序号，外层仅在新的步骤切换时回到表单顶部；普通输入不触发此滚动。

会话草稿不属于持久存储。刷新、关闭或服务会话失效后可能清空；历史成片仍以作品记录和本地文件为准。旧生成结果会明确标注为上次结果，不表示当前参数已经重新生成。

## 验证结果

- 全量离线测试：`238 passed, 256 subtests passed`。既有 `locale.getdefaultlocale` 弃用提示保留。
- TypeScript 检查与 Vite 生产构建通过。
- 本轮改动相关 Python 文件 Ruff 检查通过，中文资源按 UTF-8 读写。
- 浏览器逐项打开五页，确认三步标题、页面结构与导航一致；四类素材页可进入参数和最终步骤，缺素材时生成按钮禁用。
- 浏览器实际执行快速创作前进到第 3 步、再返回第 1 步，验证测试脚本保持。英文 Previous/Next 和步骤标题也已检查。
- AppTest 使用内存服务、真实上传管理器协议验证文件字节保持、删除、缓存复用；测试覆盖单条、批量、结果保持及校验失败返回。
- 嵌入 iframe 的浏览器自动化点击存在工具限制，步骤按钮交互另在相同服务的独立测试页验证；工作台内嵌布局通过实际页面检查。
- 未点击实际视频生成或 TTS 试听，未修改真实密钥和服务配置，未发布远端。
