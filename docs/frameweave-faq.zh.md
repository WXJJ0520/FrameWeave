# 镜织 FrameWeave 常见问题

<!-- 目录查询、配置保存和真实生成分别说明，不混用测试结论。 -->

## 第一次使用需要什么？

安装 Python 3.11+、uv、Node.js 22 或更新的受支持版本、npm、FFmpeg / ffprobe，并按 [安装指南](zh/getting-started/installation.md) 安装锁定依赖、Playwright Chromium 与前端。运行 `uv run --frozen python -m frameweave` 后打开 [本地工作台](http://127.0.0.1:8765)。

工作台在本机运行；脚本、素材理解和画面生成使用配置的 API，Edge TTS 也需网络。当前页面不要求本地 GPU。

## 应该填写哪一组密钥？

| 需求 | 系统配置中的位置 |
| --- | --- |
| 脚本、章节、标题和素材解说 | 文本模型 |
| GPT 图片、OpenAI 兼容视觉分析 | 图片与视频 → OpenAI |
| 通义图片、视频、视觉分析及已接入的数字人 / 视频编辑 | 图片与视频 → 通义 |
| Grok 或 Muse 视频 | 图片与视频 → Grok / Muse |
| Seedream 图片、Seedance 视频 | 图片与视频 → 火山 |
| 可灵视频 | 图片与视频 → 可灵 |
| Edge TTS 配音 | 创作页选择音色和语速，无需 API 密钥 |

文本与 OpenAI 媒体服务独立配置，即使用同一个中转站也需分别设置。Muse 使用你自己的 muse2api 地址与服务密钥。只配置要用的服务即可。

## 测试连接、加载、保存和生成有什么区别？

- **测试连接**：用当前输入检查查询接口，不保存、不生成。
- **设置页“从接口加载模型”**：读取目录，仍需点击底部“保存配置”。
- **保存配置**：将地址、凭据和目录写入本地配置。
- **素材页“加载并保存模型列表”**：使用已保存的视觉配置，查询后直接保存该服务目录。
- **生成**：按流程提交文案、素材分析、配音或视频任务。

查询成功不代表具备视觉能力、视频生成权限或可用余额。

## 已填密钥，为什么素材页还提示缺少模型？

密钥已填写和目录已保存是两个状态。进入 **自定义素材第二步**，选择 OpenAI 或通义，点击 **加载并保存模型列表**，再明确选择支持图片输入的型号。文本目录不能替代视觉目录。

若返回 0 个模型，检查服务是否提供目录查询。服务不提供目录时，在设置中选择“手动维护”，填写实际模型 ID，点击“应用手动目录”并保存。手工来源明确标注，不显示为接口查询成功。

## 为什么接口有模型，图片或视频下拉却没有？

文本与视觉下拉读取各自目录；图片、视频、数字人和动作迁移还需已有适配器支持相应输入、任务提交、轮询和下载。符合页面能力的已接入型号才会显示。

火山与可灵目前未接入目录查询，使用手工目录。加入未知视频型号不会自动实现生成协议。旧 `vision_models` 仅保留为历史手填数据，不自动作为目录。

## Base URL 和代理怎么填？

填写服务文档提供的 API 基础地址，不把生成路径或 `/models` 当作基础地址。地址与密钥必须来自同一服务。兼容文本接口不代表支持图片和视频接口。

媒体代理在 **网络与调试 → 本地代理** 填写，再到对应提供商启用；未启用的服务不使用这项设置。它不是文本模型的统一代理开关。本地运行时 `127.0.0.1` 指本机，不是远程中转服务器。换地址、密钥或启用的代理后需重新加载保存目录。

## 数字人口播与图生视频有什么区别？

数字人口播用人物图片和文案，先合成参考配音，再调用已接入、同时支持人物图片与参考声音的 API。当前没有直接上传口播音频的入口。Wan 的参考声音提供音色与表达参考，不保证逐字复现或精准口型同步。

图生视频用首帧图片和提示词生成运动。Grok / Muse 当前用于这类任务，不作为数字人口播或动作迁移的替代。动作迁移需人物图片、参考视频和相应视频编辑能力。

## 5–10 分钟长视频是一次生成的吗？

快速创作与自定义素材支持 5 / 8 / 10 分钟目标：先规划章节、旁白和镜头，再逐镜头配音、生成画面或复用素材，最后合成完整视频。目标时长是预算，完成后再检测实际时长。

自定义素材长片均匀取段，不足时可能复用或循环，尚未按旁白精确定位动作。原视频音轨不识别、不混入成片；成片使用生成旁白与背景音乐。当前不支持失败后的自动断点续生成。

## 素材分析支持哪些服务和文件大小？

支持 **OpenAI / 兼容视觉接口**和 **DashScope / Qwen**，分别选择图片输入模型。

按锁定依赖安装后，单视频上限 **1 GB**；视觉分析图片限制 **32 MB / 6400 万像素**，发送前缩放。视频在本机均匀抽取最多 **8 / 16 / 32 帧**，附时间发送，不上传完整视频分析。增加抽帧会增大请求，仍可能漏掉短暂动作。

默认用原素材合成；主动启用素材动画后，匹配到的图片额外调用图生视频 API。

## Edge TTS 为什么会返回 403？

Edge TTS 是在线朗读链路，不使用 OpenAI、Grok 等生成密钥。当前项目锁定 `edge-tts==7.3.1`；更新代码后执行 `uv sync --frozen`，正常停止旧服务并重启。

若仍失败，检查网络、系统时间与远端服务状态。升级无法保证在线服务始终可用。先用短文本试听，区分配音与视频生成故障。

## 构建提示 crypto.getRandomValues is not a function 怎么办？

检查 `node --version` 和 `npm --version`。`PATH` 可能仍指向 Node 16 等旧版本，需要切换到 Node.js 22 或更新的受支持版本。nvm 用户可执行 `nvm use 22` 选择已安装版本；必要时重开终端，再确认版本并重新构建。它与 API 密钥无关。

## 为什么没有新界面，或端口被占用？

日常打开 `8765`，`8501` 是内嵌创作服务。前端更新后运行 `npm --prefix studio run build`，启动器更新后重启。

启动器只复用确认属于当前仓库的 `8501` 服务。旧服务用相对脚本路径启动时可能无法确认归属；在其原终端正常退出再启动镜织，不终止不明进程。

## 配置更新会不会清空素材？草稿能永久保存吗？

下一次创作页交互会使用更新配置，可切换步骤触发更新。切换步骤和已打开的功能页保留当前会话输入与上传缓存。

刷新、关闭页面或重启仍可能丢失草稿；它不是持久项目存档。成片在创作页查看与下载，记录在“作品记录”查找。配置位于 `config.yaml`，生成内容位于 `output/`。
